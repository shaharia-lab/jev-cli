JSON Schema of a complete request: `state`, `model` and `questions`, as the API takes it

When to use:
Use `jev schema request` to author or check a file that carries everything an evaluation needs:
`state`, `model` and `questions`, exactly the body the API takes. Use `jev schema questions` for a
file whose state comes from elsewhere, and `jev validate` to check a file offline with jev's own
rules, which explain each problem and suggest the fix.

Input:
Nothing. It needs no API key and no configuration, and never uses the network.

Output:
A JSON Schema (draft 2020-12) with every definition inlined, generated from the types jev reads. It
holds the limits: 1 to 255 choice options, 2 to 10 score levels, at least one question, and no
unknown fields. JSON on a terminal too; -o yaml gives YAML.

Usage: jev schema request [OPTIONS]

Options:
  -h, --help
          Print help (see a summary with '-h')

Global options:
      --profile <NAME>
          Named profile to use (its API key, base URL and defaults) [env: `JEV_PROFILE`]

  -o, --output <FORMAT>
          Output format [default: table on a terminal, json when piped] [env: `JEV_OUTPUT`]

          Possible values:
          - table: Readable text for a person at a terminal
          - json:  One pretty-printed JSON document. The default when stdout is not a terminal
          - yaml:  One YAML document
          - jsonl: Compact JSON, one record per line

      --field <PATH>
          Print one raw value from the output, e.g. `answers.is_urgent.noul`

      --model <MODEL>
          Model alias or versioned id, e.g. `jev-latest` or `jev-1.13.0`

      --base-url <URL>
          API root [default: https://api.typesafe.ai]

      --timeout <DURATION>
          Time allowed per attempt, e.g. `30`, `30s`, `500ms` or `2m` [default: 30s]

      --max-retries <N>
          Retries after the first attempt; 0 disables retrying [default: 2]

      --no-input
          Never ask for input; fail with an error naming the flag to use instead

          [env: JEV_NO_INPUT=]

      --no-color
          Disable colour (also honours the `NO_COLOR` environment variable)

      --ascii
          Use only ASCII characters in human-readable output

      --insecure-allow-http
          Allow a plain http:// base URL to a host other than localhost (the API key travels
          unencrypted)

      --debug-bodies
          Log request and response bodies with -v; `state` may contain sensitive data

  -q, --quiet
          Print errors only; suppress notices and warnings on stderr

  -v, --verbose...
          Log to stderr; repeat for more (-v requests and retries, -vv everything)

Exit codes:
  0    success, and any gate condition holds
  2    usage or validation error; nothing was sent

Examples:
  # Save it for an editor or a JSON Schema validator
  jev schema request -o json > jev-request.schema.json

  # The fields a question may have
  jev schema request | jq '.properties.questions.additionalProperties'
