Print the version, commit, build date and target

When to use:
Use `jev version` to report the jev you run, e.g. in a bug report. Use `jev --version` for the bare
version, and `jev models list` for the model versions the API offers.

Input:
Nothing.

Output:
`version`, `commit`, `build_date`, `target`, `client_version`, `install_method` (`self_managed` for
the install script, `homebrew`, `cargo` or `unknown`), `update_channel` (`stable` or `prerelease`,
from `update.channel`) and `auto_update`: `enabled`, and the `reason` when it is off, naming the
first guard that applies (a package manager, a configuration that cannot be read, JEV_AUTO_UPDATE or
`update.auto`, `update.pin_version`, CI=true, an install not made by the install script, or a
directory jev cannot write to). `--field version` prints just the version.

Usage: jev version [OPTIONS]

Options:
  -h, --help
          Print help (see a summary with '-h')

Global options:
      --profile <NAME>
          Named profile to use (its API key, base URL and defaults) [env: `JEV_PROFILE`]

  -o, --output <FORMAT>
          Output format [default: table on a terminal, json when piped] [env: `JEV_OUTPUT`]

          Possible values:
          - table: Readable text for a person at a terminal
          - json:  One pretty-printed JSON document. The default when stdout is not a terminal
          - yaml:  One YAML document
          - jsonl: Compact JSON, one record per line

      --field <PATH>
          Print one raw value from the output, e.g. `answers.is_urgent.noul`

      --model <MODEL>
          Model alias or versioned id, e.g. `jev-latest` or `jev-1.13.0`

      --base-url <URL>
          API root [default: https://api.typesafe.ai]

      --timeout <DURATION>
          Time allowed per attempt, e.g. `30`, `30s`, `500ms` or `2m` [default: 30s]

      --max-retries <N>
          Retries after the first attempt; 0 disables retrying [default: 2]

      --no-input
          Never ask for input; fail with an error naming the flag to use instead

          [env: JEV_NO_INPUT=]

      --no-color
          Disable colour (also honours the `NO_COLOR` environment variable)

      --ascii
          Use only ASCII characters in human-readable output

      --insecure-allow-http
          Allow a plain http:// base URL to a host other than localhost (the API key travels
          unencrypted)

      --debug-bodies
          Log request and response bodies with -v; `state` may contain sensitive data

  -q, --quiet
          Print errors only; suppress notices and warnings on stderr

  -v, --verbose...
          Log to stderr; repeat for more (-v requests and retries, -vv everything)

Exit codes:
  0    success, and any gate condition holds

Examples:
  # Everything about this build
  jev version

  # Just the version, for a script
  jev version --field version

  # Does this jev update itself, and if not, why not?
  jev version -o json | jq .auto_update
