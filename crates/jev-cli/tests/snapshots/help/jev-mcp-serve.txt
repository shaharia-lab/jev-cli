Serve jev's tools to an MCP client (Claude Code, Claude Desktop, Cursor, VS Code) over stdio

When to use:
Use `jev mcp serve` when an AI agent should call Jev as a tool, through an MCP client such as Claude
Code, Claude Desktop, Cursor or VS Code. From a shell script or CI, call `jev eval`, `jev noul`,
`jev choice` or `jev score` directly instead.

Input:
The Model Context Protocol on stdin, one JSON-RPC message per line, until the client closes stdin.
Tools: evaluate (a state and many questions), noul, choice, score (one question each), validate
(offline, needs no key) and list_models. The API key, base URL and model come from the usual places
(--profile, the environment, the profile), read once at start-up; the key is never part of a tool's
input, result or error. Every call is validated offline before anything is sent.

Output:
Protocol messages only on stdout; logs, notices and warnings go to stderr. A tool result is the same
JSON envelope as `jev eval -o json`, plus `session` (calls made and estimated spend so far). A
failure is a tool error carrying the JSON error object `jev` prints on stderr, and an invalid
request is a tool error listing every finding. API failures never end the server; if stdout cannot
be written, it exits 1.

Usage: jev mcp serve [OPTIONS]

Options:
  -h, --help
          Print help (see a summary with '-h')

Guardrails:
      --max-cost-usd-per-call <USD>
          Refuse, before sending, any call whose estimated cost in US dollars is above this

Global options:
      --profile <NAME>
          Named profile to use (its API key, base URL and defaults) [env: `JEV_PROFILE`]

  -o, --output <FORMAT>
          Output format [default: table on a terminal, json when piped] [env: `JEV_OUTPUT`]

          Possible values:
          - table: Readable text for a person at a terminal
          - json:  One pretty-printed JSON document. The default when stdout is not a terminal
          - yaml:  One YAML document
          - jsonl: Compact JSON, one record per line

      --field <PATH>
          Print one raw value from the output, e.g. `answers.is_urgent.noul`

      --model <MODEL>
          Model alias or versioned id, e.g. `jev-latest` or `jev-1.13.0`

      --base-url <URL>
          API root [default: https://api.typesafe.ai]

      --timeout <DURATION>
          Time allowed per attempt, e.g. `30`, `30s`, `500ms` or `2m` [default: 30s]

      --max-retries <N>
          Retries after the first attempt; 0 disables retrying [default: 2]

      --no-input
          Never ask for input; fail with an error naming the flag to use instead

          [env: JEV_NO_INPUT=]

      --no-color
          Disable colour (also honours the `NO_COLOR` environment variable)

      --ascii
          Use only ASCII characters in human-readable output

      --insecure-allow-http
          Allow a plain http:// base URL to a host other than localhost (the API key travels
          unencrypted)

      --debug-bodies
          Log request and response bodies with -v; `state` may contain sensitive data

  -q, --quiet
          Print errors only; suppress notices and warnings on stderr

  -v, --verbose...
          Log to stderr; repeat for more (-v requests and retries, -vv everything)

Exit codes:
  0    the client closed stdin
  2    usage, or a broken configuration

Examples:
  # Register with Claude Code
  claude mcp add jev -- jev mcp serve

  # Refuse any call estimated above a tenth of a cent (pin a versioned model so it has a price)
  jev mcp serve --model jev-1.13.0 --max-cost-usd-per-call 0.001

  # Use a profile's key and settings; logs go to stderr, never stdout
  jev mcp serve --profile work -v

  # Check it from a shell: list the tools' names
  echo '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | jev mcp serve \
    | jq -r '.result.tools[].name'
