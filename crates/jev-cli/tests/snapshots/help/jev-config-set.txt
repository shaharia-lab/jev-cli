Store a setting in the selected profile

When to use:
Use `jev config set` to store a default in the selected profile, so that you do not repeat a flag.
For one run, pass the flag or set the environment variable instead; `jev config unset` restores the
default. The API key is not a setting: use `jev auth login`.

Input:
KEY and VALUE. The value is checked before anything is written: `timeout` takes `30s` or `500ms`,
`output` takes table, json, yaml or jsonl, and so on. --profile chooses the profile to change.

Output:
`profile`, `key`, `value` and `changed`.

Usage: jev config set [OPTIONS] <KEY> <VALUE>

Arguments:
  <KEY>
          Setting name: `base_url`, `model`, `output`, `timeout`, `max_retries`, `concurrency` or
          `warn_unpinned`

  <VALUE>
          The new value, e.g. `jev-1.13.0`, `45s`, `json` or `false`

Options:
  -h, --help
          Print help (see a summary with '-h')

Global options:
      --profile <NAME>
          Named profile to use (its API key, base URL and defaults) [env: `JEV_PROFILE`]

  -o, --output <FORMAT>
          Output format [default: table on a terminal, json when piped] [env: `JEV_OUTPUT`]

          Possible values:
          - table: Readable text for a person at a terminal
          - json:  One pretty-printed JSON document. The default when stdout is not a terminal
          - yaml:  One YAML document
          - jsonl: Compact JSON, one record per line

      --field <PATH>
          Print one raw value from the output, e.g. `answers.is_urgent.noul`

      --model <MODEL>
          Model alias or versioned id, e.g. `jev-latest` or `jev-1.13.0`

      --base-url <URL>
          API root [default: https://api.typesafe.ai]

      --timeout <DURATION>
          Time allowed per attempt, e.g. `30`, `30s`, `500ms` or `2m` [default: 30s]

      --max-retries <N>
          Retries after the first attempt; 0 disables retrying [default: 2]

      --no-input
          Never ask for input; fail with an error naming the flag to use instead

          [env: JEV_NO_INPUT=]

      --no-color
          Disable colour (also honours the `NO_COLOR` environment variable)

      --ascii
          Use only ASCII characters in human-readable output

      --insecure-allow-http
          Allow a plain http:// base URL to a host other than localhost (the API key travels
          unencrypted)

      --debug-bodies
          Log request and response bodies with -v; `state` may contain sensitive data

  -q, --quiet
          Print errors only; suppress notices and warnings on stderr

  -v, --verbose...
          Log to stderr; repeat for more (-v requests and retries, -vv everything)

Exit codes:
  0    the setting is stored
  2    not a setting, a value it does not accept, or the configuration cannot be written

Examples:
  # Pin a versioned model once thresholds are tuned against it
  jev config set model jev-1.13.0

  # A longer timeout for the ci profile
  jev config set timeout 45s --profile ci -o json
