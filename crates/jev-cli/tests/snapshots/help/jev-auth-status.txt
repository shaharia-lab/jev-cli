Show whether a key is configured, where it comes from, and whether the API accepts it

When to use:
Use `jev auth status` to find out whether jev has an API key, where it comes from (the environment
or the credentials file) and whether the API accepts it. Use `jev auth login` to store a key, and
`jev models list` to see what the key gives access to.

Input:
Nothing. --profile chooses the profile; --offline skips the check against the API.

Output:
`profile`, `authenticated`, `source` (`env` or `file`), `fingerprint` (the last four characters of
the key), `base_url` and `check` (`ok`, and `detail` when it failed). The key itself is never shown.

Usage: jev auth status [OPTIONS]

Options:
      --offline
          Do not check the key against the API

  -h, --help
          Print help (see a summary with '-h')

Global options:
      --profile <NAME>
          Named profile to use (its API key, base URL and defaults) [env: `JEV_PROFILE`]

  -o, --output <FORMAT>
          Output format [default: table on a terminal, json when piped] [env: `JEV_OUTPUT`]

          Possible values:
          - table: Readable text for a person at a terminal
          - json:  One pretty-printed JSON document. The default when stdout is not a terminal
          - yaml:  One YAML document
          - jsonl: Compact JSON, one record per line

      --field <PATH>
          Print one raw value from the output, e.g. `answers.is_urgent.noul`

      --model <MODEL>
          Model alias or versioned id, e.g. `jev-latest` or `jev-1.13.0`

      --base-url <URL>
          API root [default: https://api.typesafe.ai]

      --timeout <DURATION>
          Time allowed per attempt, e.g. `30`, `30s`, `500ms` or `2m` [default: 30s]

      --max-retries <N>
          Retries after the first attempt; 0 disables retrying [default: 2]

      --no-input
          Never ask for input; fail with an error naming the flag to use instead

          [env: JEV_NO_INPUT=]

      --no-color
          Disable colour (also honours the `NO_COLOR` environment variable)

      --ascii
          Use only ASCII characters in human-readable output

      --insecure-allow-http
          Allow a plain http:// base URL to a host other than localhost (the API key travels
          unencrypted)

      --debug-bodies
          Log request and response bodies with -v; `state` may contain sensitive data

  -q, --quiet
          Print errors only; suppress notices and warnings on stderr

  -v, --verbose...
          Log to stderr; repeat for more (-v requests and retries, -vv everything)

Exit codes:
  0    a key is configured, and the API accepts it (or --offline)
  2    the configuration cannot be read
  3    no key is configured, or the API refused it

Examples:
  # Is there a key, and does it work?
  jev auth status

  # Check without the network, for a script
  jev auth status --offline --field authenticated
