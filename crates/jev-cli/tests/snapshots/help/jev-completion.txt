Print a shell completion script

When to use:
Use `jev completion` once, when installing jev, to make the shell complete its commands, flags and
flag values on Tab. The script is generated from the same definitions as the help, so re-run it
after upgrading jev. It is for people at a shell: a program or an AI agent that needs the command
tree should read `jev spec` instead.

Input:
SHELL: bash, zsh, fish or powershell. Nothing else is read: no API key, no configuration, no
network.

Output:
The completion script, printed as is on stdout whatever --output says. Load it from the shell's
start-up file or save it where the shell looks for completions (see the examples).

Usage: jev completion [OPTIONS] <SHELL>

Arguments:
  <SHELL>
          The shell to print the script for

          Possible values:
          - bash:       For Bash, to source from ~/.bashrc
          - zsh:        For Zsh, to source from ~/.zshrc or save as `_jev` in a directory on $fpath
          - fish:       For fish, to save as ~/.config/fish/completions/jev.fish
          - powershell: For PowerShell 5.1 or 7, to load from $PROFILE

Options:
  -h, --help
          Print help (see a summary with '-h')

Global options:
      --profile <NAME>
          Named profile to use (its API key, base URL and defaults) [env: `JEV_PROFILE`]

  -o, --output <FORMAT>
          Output format [default: table on a terminal, json when piped] [env: `JEV_OUTPUT`]

          Possible values:
          - table: Readable text for a person at a terminal
          - json:  One pretty-printed JSON document. The default when stdout is not a terminal
          - yaml:  One YAML document
          - jsonl: Compact JSON, one record per line

      --field <PATH>
          Print one raw value from the output, e.g. `answers.is_urgent.noul`

      --model <MODEL>
          Model alias or versioned id, e.g. `jev-latest` or `jev-1.13.0`

      --base-url <URL>
          API root [default: https://api.typesafe.ai]

      --timeout <DURATION>
          Time allowed per attempt, e.g. `30`, `30s`, `500ms` or `2m` [default: 30s]

      --max-retries <N>
          Retries after the first attempt; 0 disables retrying [default: 2]

      --no-input
          Never ask for input; fail with an error naming the flag to use instead

          [env: JEV_NO_INPUT=]

      --no-color
          Disable colour (also honours the `NO_COLOR` environment variable)

      --ascii
          Use only ASCII characters in human-readable output

      --insecure-allow-http
          Allow a plain http:// base URL to a host other than localhost (the API key travels
          unencrypted)

      --debug-bodies
          Log request and response bodies with -v; `state` may contain sensitive data

  -q, --quiet
          Print errors only; suppress notices and warnings on stderr

  -v, --verbose...
          Log to stderr; repeat for more (-v requests and retries, -vv everything)

Exit codes:
  0    success, and any gate condition holds
  2    no shell, or one jev has no script for

Examples:
  # Bash: add this line to ~/.bashrc
  source <(jev completion bash)

  # Zsh: add this line to ~/.zshrc, after compinit
  source <(jev completion zsh)

  # Fish: save it where fish loads completions from
  jev completion fish > ~/.config/fish/completions/jev.fish

  # PowerShell: add this line to $PROFILE
  jev completion powershell | Out-String | Invoke-Expression
